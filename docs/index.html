🔒 隐私政策

生效日期：2026-08-16 · 适用范围：考研智复习 · AI刷题助手（Chrome 浏览器插件）

我们高度重视你的隐私。本插件遵循数据本地优先（Local-first）设计：除调用你主动配置的 AI 服务外，不向任何服务器上传你的数据。请阅读本政策了解我们如何处理你的信息。

1. 我们收集哪些数据

数据类型内容存储位置是否上传
AI 配置你填写的 API Key、API 地址、模型名称浏览器本地（chrome.storage.local）❌ 仅在调用 AI 服务时用于认证，不上传到其他服务器
学习数据错题本、答题记录、复习队列、知识库、学习报告浏览器本地❌ 不上传
备考目标目标院校、专业课、章节、每日目标浏览器本地❌ 不上传
AI 调用内容你发起的出题/讲解请求内容及 AI 返回内容不持久化存储✅ 发送至你配置的 AI 服务商（默认 DeepSeek）处理
使用日志（元数据）调用时间、操作类型、是否被安全过滤、内容长度浏览器本地❌ 不上传

2. 数据的用途

  • 学习数据：仅用于本插件的核心功能——出题练习、错题管理、遗忘曲线复习提醒、学习报告生成。
  • AI 调用内容：仅在调用 AI 服务时发送给对应服务商（默认 DeepSeek，见其 API 服务条款），用于生成题目与讲解。
  • 使用日志：仅用于安全审计与故障排查（详见第 5 节）。

3. 我们不做什么

  • ❌ 不收集你的浏览历史、Cookie、表单输入
  • ❌ 不追踪你的跨站行为
  • ❌ 不向你推送广告
  • ❌ 不将你的数据出售或共享给任何第三方广告商
  • ❌ 不在无你主动操作的情况下访问任何网页内容

4. 第三方服务

  • AI 服务商（默认 DeepSeek）：当你发起 AI 调用时，你的请求内容会发送至你配置的 AI 服务商。请阅读 DeepSeek 的隐私政策了解其数据处理方式。
  • 本插件不使用任何分析 SDK、统计服务或追踪脚本。

5. 内容安全与日志

为履行内容安全义务，本插件：

  • 对 AI 调用输入/输出做基础敏感词过滤，拦截极端不当内容；
  • 记录仅含元数据的使用日志（时间、类型、是否被拦截、内容长度），不记录输入/输出原文；
  • 日志仅存浏览器本地，可随时在设置页清空。

6. 数据删除与控制

你有完全的控制权：

  • 在设置页点击 "清空数据" 可删除全部学习数据；
  • 在设置页点击 "导出数据" 可导出本地数据备份；
  • 卸载插件即删除所有本地存储的数据；
  • API Key 可随时在设置页修改或清空。

7. 数据安全

  • 数据仅存储在浏览器本地（chrome.storage.local），由浏览器沙箱保护；
  • API Key 通过 background service worker 转发，不暴露给普通网页；
  • 我们建议你为 API Key 设置消费上限，并在不使用时删除。

8. 未成年人

本插件面向考研备考用户（通常为成年人）。若你未满 18 周岁，请在监护人指导下使用。

9. 政策更新

我们可能不时更新本隐私政策。重大变更会在插件设置页显著位置提示。继续使用本插件即表示你接受更新后的政策。

10. 联系我们

如有隐私相关问题，请通过插件商店页面的开发者联系方式与我们联系。
