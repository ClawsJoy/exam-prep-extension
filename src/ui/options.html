🔑 DeepSeek API Key 配置

第一步：获取 API Key（约 2 分钟） 1. 访问 platform.deepseek.com，登录或注册账号
2. 左侧导航栏选择「API Keys」→ 点击「创建 API Key」
3. 输入名称（如"考研复习插件"）→ 点击创建
4. 立即复制保存生成的 Key（格式 sk-xxxx）——关闭弹窗后就看不到了
5. 如遗失只能删除重建；建议设置消费上限，避免意外费用
⚠️ 安全提醒 API Key 是你账户的"通行证"，不要分享给任何人、不要截图发到网上。 建议设置消费上限；可在设置中随时清除。Key 仅保存在浏览器本地，不会上传到任何服务器。
